# BioPlot

BioPlot is a bilingual Persian/English scientific visualization platform for creating scientific figures, plots, pathways, networks, and publication-ready visual assets.

## Current prototype

The repository currently contains the first interactive BioPlot Editor prototype with:

- Scientific asset library
- Templates
- Design tools (text, shapes, arrows, labels)
- Future-facing Plots & Data workspace
- Interactive canvas and draggable objects
- Properties and layers panels
- Zoom, grid, undo/redo, duplicate/delete
- Persian/English interface toggle

## Product direction

BioPlot is being designed as a broader scientific visualization workspace rather than only a figure illustrator.

Planned product areas:

- BioPlot Figures
- BioPlot Plots
- BioPlot Pathways
- BioPlot Networks
- BioPlot AI

## Run locally

Open `index.html` in a modern browser.

Later stages will migrate the prototype into a component-based frontend and connect authentication, project storage, asset management, and deployment infrastructure.
